# 卡片收尾

开没开以模式中心的注入为准。看不到「卡片开」，就不要自行开启，也不要去文件或其他会话里找。

过程、工具进展、内部交接用文字。面向用户的结论用一张卡。内容短，不是跳过卡片的理由。

先读匹配的已安装 recipe。没有对应配方就用 hana-folio 官方模板，不合适再用 hana-card-style。用户没要求自定义视觉，就不另造风格。

精简用一张小 overview。专业仍是一张卡，把该用的对比、步骤、来源放进去，不要另写一篇长文。

追问放哪，只听注入那句，不要自己猜。注入写着「放进结论卡」时，三条放进这张卡，卡片后面不要再写一份。这张卡若是天气这类专用卡、放不下追问，就写在卡片后面，不要吞掉，也不要为了追问再铸一张卡。注入写着「写在卡片后面」或「写在回答末尾」时，不要放进卡内。

`show_card` 有成功回执才算发卡。失败就说明本轮没展示，用精炼正文把结论说完。同一份结论已经成功展示过，不要再铸一张。宿主要求正文时，卡片外只留一句衔接。

子 Agent 内部任务不向用户铸卡。没有新信息的重复后台回执不铸卡。

注入写着本轮跳过卡片时，这一条用文字，下一轮恢复。
